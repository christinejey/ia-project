# C4 Model — ia-project

> Три уровня архитектурных диаграмм: Context → Container → Component

---

## Level 1 — System Context

Показывает систему целиком и её связи с пользователями и внешними системами.

```mermaid
C4Context
    title System Context — ia-project

    Person(user, "Пользователь", "Открывает чат в браузере")
    Person(dev, "Разработчик", "Пишет код, делает git push")

    System(chatApp, "ia-project", "Instagram-like чат на Cloudflare Workers с историей сообщений")

    System_Ext(github, "GitHub", "Хранит исходный код и запускает CI/CD pipeline")
    System_Ext(cloudflare, "Cloudflare", "Исполняет Worker на edge, хранит данные в KV")

    Rel(user, chatApp, "Открывает чат", "HTTPS")
    Rel(dev, github, "git push", "SSH")
    Rel(github, cloudflare, "wrangler deploy", "Cloudflare API / HTTPS")
    Rel(chatApp, cloudflare, "Работает на платформе")
```

## Level 2 — Container

Показывает из каких контейнеров состоит система и как они взаимодействуют.

```mermaid
C4Container
    title Container Diagram — ia-project

    Person(user, "Пользователь")
    Person(dev, "Разработчик")

    System_Boundary(githubBoundary, "GitHub") {
        Container(repo, "Repository", "Git", "Исходный код: TypeScript worker, конфиги CI/CD, ADR")
        Container(ci, "CI Pipeline", "GitHub Actions", "4 параллельных job: Lint · Dependency Scan · Secret Scan · Static Analysis")
        Container(cd, "CD Pipeline", "GitHub Actions", "Запускается только после успешного CI через workflow_run")
    }

    System_Boundary(cfBoundary, "Cloudflare Platform") {
        Container(worker, "userchat-worker", "TypeScript · V8 Isolate", "HTTP-роутер + REST API + встроенный HTML/CSS/JS интерфейс")
        ContainerDb(kv, "userchat-kv", "Cloudflare KV", "key: 'chats' → Chat[]\nkey: 'messages:{id}' → Message[]")
    }

    Rel(user, worker, "GET / · GET|POST|DELETE /api/*", "HTTPS")
    Rel(dev, repo, "git push", "SSH")
    Rel(repo, ci, "Запускает на push / pull_request", "GitHub webhook")
    Rel(ci, cd, "Запускает при conclusion=success", "workflow_run event")
    Rel(cd, worker, "npx wrangler deploy", "Cloudflare API")
    Rel(worker, kv, "get · put · delete", "KV Binding (env.CHAT_KV)")
```

## Level 3 — Component

Показывает внутреннюю структуру `userchat-worker`.

```mermaid
C4Component
    title Component Diagram — userchat-worker (src/index.ts)

    Person(user, "Пользователь")
    ContainerDb(kv, "Cloudflare KV", "userchat-kv")

    Container_Boundary(workerBoundary, "userchat-worker") {
        Component(router, "HTTP Router", "fetch() handler", "Разбирает pathname + method, направляет к нужному обработчику")

        Component(htmlRenderer, "HTML Renderer", "TypeScript const", "Возвращает встроенный HTML/CSS/JS на GET /")

        Component(chatHandler, "Chat Handler", "TypeScript", "GET /api/chats — список чатов\nPOST /api/chats — создать чат\nDELETE /api/chats/:id — удалить чат + его сообщения")

        Component(msgHandler, "Message Handler", "TypeScript", "GET /api/chats/:id/messages — история\nPOST /api/chats/:id/messages — сохранить сообщение и вернуть эхо-ответ")

        Component(kvAdapter, "KV Adapter", "TypeScript", "getChats() · getMessages()\nenv.CHAT_KV.get · put · delete")
    }

    Rel(user, router, "HTTP request", "HTTPS")
    Rel(router, htmlRenderer, "GET /")
    Rel(router, chatHandler, "GET|POST /api/chats\nDELETE /api/chats/:id")
    Rel(router, msgHandler, "GET|POST /api/chats/:id/messages")
    Rel(chatHandler, kvAdapter, "read / write chats")
    Rel(msgHandler, kvAdapter, "read / write messages")
    Rel(kvAdapter, kv, "env.CHAT_KV binding", "Cloudflare KV API")
```

## Level 2 (дополнение) — CI/CD Pipeline

Детализация процесса доставки кода в продакшн.

```mermaid
C4Container
    title CI/CD Pipeline — ia-project

    Person(dev, "Разработчик")

    System_Boundary(githubBoundary, "GitHub Actions") {
        Container(push, "git push → main", "Git event", "Триггер всей цепочки")

        System_Boundary(ciBoundary, "CI Pipeline (параллельно)") {
            Container(lint, "Lint", "ESLint + @typescript-eslint", "Стиль кода, ошибки, deprecated API")
            Container(depScan, "Dependency Scan", "npm audit --audit-level=high", "CVE в пакетах уровня high/critical")
            Container(secretScan, "Secret Scan", "Gitleaks Action v2", "Токены и пароли в коде и git-истории")
            Container(staticAnalysis, "Static Analysis", "tsc --noEmit strict", "Ошибки типов TypeScript")
        }

        Container(cd, "CD Pipeline", "wrangler deploy", "Запускается только если CI = success")
    }

    System_Ext(cloudflare, "Cloudflare Workers", "userchat-worker.christina-api.workers.dev")

    Rel(dev, push, "git push", "SSH")
    Rel(push, lint, "trigger")
    Rel(push, depScan, "trigger")
    Rel(push, secretScan, "trigger")
    Rel(push, staticAnalysis, "trigger")
    Rel(lint, cd, "success →")
    Rel(depScan, cd, "success →")
    Rel(secretScan, cd, "success →")
    Rel(staticAnalysis, cd, "success →")
    Rel(cd, cloudflare, "deploy", "Cloudflare API")
```

## Ключевые структуры данных в KV

```
KV namespace: userchat-kv
│
├── "chats"
│     └── Chat[]
│           ├── id: string (UUID)
│           ├── name: string
│           └── createdAt: number (timestamp)
│
└── "messages:{chatId}"
      └── Message[]
            ├── id: string (UUID)
            ├── role: "user" | "assistant"
            ├── content: string
            └── timestamp: number
```

## Маршруты API

| Метод | Путь | Действие |
|---|---|---|
| `GET` | `/` | Отдать HTML интерфейс |
| `GET` | `/api/chats` | Список всех чатов |
| `POST` | `/api/chats` | Создать новый чат |
| `DELETE` | `/api/chats/:id` | Удалить чат и его сообщения |
| `GET` | `/api/chats/:id/messages` | История сообщений чата |
| `POST` | `/api/chats/:id/messages` | Отправить сообщение (эхо-ответ) |
