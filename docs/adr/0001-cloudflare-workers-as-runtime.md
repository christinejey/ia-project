# ADR-0001: Cloudflare Workers как среда выполнения

## Статус
Принято

## Контекст
Проекту нужна серверная среда для обработки HTTP-запросов и хранения данных чата. Варианты рассматривались:
- Традиционный VPS / контейнер (Node.js, Deno)
- Serverless функции (AWS Lambda, Vercel Functions)
- Cloudflare Workers (edge runtime)

## Решение
Использовать **Cloudflare Workers** как единственную среду выполнения.

Весь код — один TypeScript-файл `workers/userchat/src/index.ts`, который:
- обрабатывает HTTP-маршруты вручную через `URL.pathname`
- отдаёт HTML-интерфейс как строку из того же файла
- обращается к Cloudflare KV через биндинг `env.CHAT_KV`

## Обоснование
- **Нет холодного старта** — Workers работают на V8 Isolates, запуск < 1 мс
- **Бесплатный тир** — 100 000 запросов в день без оплаты
- **Глобальная CDN** — код исполняется в ближайшем к пользователю дата-центре
- **Встроенное хранилище** — KV namespace подключается без сторонних сервисов
- **Простой деплой** — одна команда `wrangler deploy`

## Последствия
- Ограничение среды выполнения: нет доступа к Node.js API (`fs`, `net`, `child_process`)
- Максимальное время выполнения запроса — 30 секунд (CPU time 10 мс на бесплатном тире)
- KV eventual consistent — не подходит для транзакций
- Размер Worker bundle ограничен 1 МБ (сжатый)
